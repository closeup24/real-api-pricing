# Real API Pricing — форк с вкладкой AA Task Cost

Форк открытого проекта Real API Pricing (remote `upstream`, на GitHub — `Fei2411/real-api-pricing`). Форк добавляет вкладку AA Task Cost: стоимость задач Artificial Analysis по квотам подписок. Обзор — раздел форка в начале `README.md`, метод и источники — `AA_COSTS.md`; ниже в README идёт исходная документация проекта.

## Язык

- Документация форка, комментарии и коммиты — по-русски; код, команды, имена файлов и API — без перевода.
- Файлы исходного проекта на английском и китайском не переводить.

## Ветки

- `main` — копия исходного проекта без своих коммитов. Работа форка и эти правила — в ветке `aa-task-costs`.
- Обновлять форк из `upstream` и сливать ветки — только по просьбе пользователя.

## Что где

- `extensions/aa-costs/` — расширение форка: скрипты расчёта и загрузки, тесты, `docs/`, закреплённые снимки `data/`.
- `web/` — сайт на Vite и React. Вкладка форка — `src/AACosts.tsx` и `src/aa*.ts`, интерфейс исходного проекта — `src/UpstreamApp.tsx`. Скрипты `web/scripts/build-data.mjs` и `build-aa-data.mjs` собирают `web/public/data/`.
- `scripts/` — сборка исходного проекта на Python и Node, порядок команд — `BUILD.md`. `scripts/start-local.mjs` — локальный запуск сайта.
- Только на ПК, в Git не входят: `_backup/`, `output/`, `_build/`, `.codex/`, `web/public/data/`, `web/dist/`.

## Данные и сборки в Git — исключение для форка

Общее правило держит данные и артефакты вне Git. Здесь они остаются по решению пользователя от 16.10.2026:

- `charts/`, `derived/`, `data/research/`, `data/adopted.csv` — публикация исходного проекта. README на GitHub показывает графики из `charts/`, сайт собирается из `derived/` и `data/research/`, а исходный проект меняет эти папки почти в каждом коммите. Не удалять их из Git и не пересобирать без задачи, иначе обновления из `upstream` дадут конфликты.
- `extensions/aa-costs/data/` — закреплённые снимки расширения, без них сайт не собирается. Снимки сверяются по SHA-256 байтов (`extensions/aa-costs/.gitattributes`): не менять переводы строк, обновлять только командами `fetch_*` из `extensions/aa-costs/README.md` и только по просьбе пользователя.
- Новые данные — по правилам обезличивания из `PUBLICATION.md`.

## Запуск и проверка

- `npm start` из корня: при необходимости ставит веб-зависимости, готовит данные и запускает сайт на http://127.0.0.1:8766 (вкладка `/#board=aa_combined`).
- Зависимости: `npm --prefix web ci`. Тесты: `npm --prefix web test`; сборка: `npm --prefix web run build`. Обе команды сначала готовят данные (`npm run data`).
- В облаке (Linux, клон из GitHub) те же команды работают: все входные данные в Git. Нужен Node.js 20.19+ или 22.12+.
- Графики исходного проекта пересобираются по `BUILD.md` (Python 3.10+, matplotlib, Node sharp, китайские шрифты) — только по задаче.
