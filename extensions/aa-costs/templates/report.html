API-цена из расходов AA

Средняя цена миллиона токенов в нагрузке бенчмарка — отдельно для каждого effort.

Для задачи восстанавливаем токены каждой категории из расходов AA и API-тарифов. Для полного набора делим расходы на опубликованное число входных и выходных токенов. Эффективная цена может меняться с effort из-за долей входа, кэша, ответа и reasoning; это другая смесь токенов, чем фиксированный профиль Real API Pricing.

Токены категории = расход / тариф × 1 000 000Средняя цена = все расходы / все токены × 1 000 000Для задачи знаменатель восстановлен по категориям; для набора использован опубликованный AA total. Сверка с опубликованными output задачи и total набора проверяет согласованность данных AA, но не заменяет проверку по журналу биллинга.

Три доли суммируются в 100% до округления. Во входе отдельно подписаны обычный вход и запись кэша: тарифы у них могут различаться. Выход включает ответ и reasoning. Доли считаются по восстановленной разбивке; «≈» отмечает расхождение со счётчиками AA. API-база, дополненная из AA, показана в колонке «Ставки AA × смесь RAP»; в колонке RAP для неё указано «Нет в RAP». Для набора прямая цена использует опубликованный total, даже если восстановленная разбивка приближённая.

Как читать оценки

Один и тот же коэффициент тарифа применяется ко всем доступным effort модели. Intelligence Index и исходный профиль задач наследуются из AA; коэффициент не добавляет модели интеллекта.

Цена задачи AA — взвешенная оценка по тестам, полная стоимость — цена прохождения набора. Между этими величинами нет одного общего количества задач для всех моделей.

Пересчёт приблизителен: структура токенов, кэш и использование квоты в Real API Pricing могут отличаться от нагрузки AA. При меньшем использовании квоты фактическая цена подписки на задачу будет выше.
