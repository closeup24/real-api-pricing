# Квоты и ставки для нагрузки AA

`data/pricing/quota-rates.json` содержит все **36** строк `workload=standard` из принятого снимка RAP `6489b60a14680a5ce848131d461a90eb054d03ac`: GLM Coding — 18, OpenCode Go — 5, Command Code GOAT — 7, Ollama — 6. Для расчёта доступны **27** строк. Девять GLM old сохранены со статусом `unavailable`: исходный RAP совмещает цену V2 с квотой V3, а совместимость этих условий не подтверждена. Исходный `pricing.json` не изменён.

Квоты извлечены из исходных денежных пулов и баллов. Они **не восстановлены** умножением округлённых `monthly_tokens` на цену фиксированной смеси. Ни стандартная смесь RAP, ни его готовая цена токена не участвуют в новом расчёте:

```
расход_квоты_за_задачу = Σ(токены_AA_категории × ставка_канала_категории) / 1 000 000
задач_в_месяц = monthly_quota / расход_квоты_за_задачу
цена_задачи_USD = monthly_usd × расход_квоты_за_задачу / monthly_quota
```

Для полного набора используется его собственная разбивка токенов. Ставки применяются к пяти непересекающимся категориям: `non_cache_input`, `cache_read`, `cache_write`, `answer`, `reasoning`. Их единица — `quota_unit` за миллион токенов; `monthly_quota` выражена в той же единице. В долларовых каналах `USD` означает номинал usage credits, а не оплату подписки.

## Исходные квоты

| Канал | Принятая месячная квота | Основа |
|---|---:|---|
| OpenCode Go | $15 на каждую из пяти моделей | `min($60 общий пул, $15 лимит модели)` |
| Command Code GOAT / Sol | $70 | `min($70 общий пул, $70 лимит модели)` |
| Command Code GOAT / DeepSeek 4.1, GLM Flash, Gemini | $40 | `min($70, $40)` |
| Command Code GOAT / Luna, MiMo, Grok | $20 | `min($70, $20)` |
| Ollama Pro / Max | $60 / $300 | Общий месячный пул; отдельный лимит модели не найден |
| GLM V3 new Lite / Pro / Max | 40 000 / 240 000 / 560 000 points | Недельные 10 000 / 60 000 / 140 000 × четыре недели; не переносятся на V2 old |

Это сценарии использования одной модели. Общий пул нельзя повторно сложить по всем доступным моделям. Пятичасовые и недельные ограничения сохранены в `additional_limits`; арифметика месяца предполагает возможность использовать их полностью. Она не моделирует календарь выполнения задач.

## Ставки и статусы

В строгой классификации полного пятикомпонентного расчёта получилось **0 documented, 27 assumed, 9 unavailable**. Это не означает, что все исходные ставки неизвестны: три основные категории доступных тарифов взяты из опубликованных таблиц канала. `quota_basis_status` и `component_rate_status` показывают, какая часть подтверждена. Общий статус `documented` требует однозначного сопоставления всех пяти категорий и условий тарифа. Несовместимые поколения цены и квоты не допускаются в расчёт даже с пометкой `assumed`.

Во всех 27 доступных строках reasoning сопоставлен output-ставке, но отдельного подтверждения этого правила в сохранённых данных канала нет. Такое сопоставление явно записано как допущение. У 24 доступных строк отсутствует отдельная ставка cache write: принята input-ставка, а не нулевая стоимость. Это не утверждение, что отдельная тарификация записи заведомо отсутствует.

У трёх строк cache write указана в research и использована без подстановки:

| Канал и модель | Input | Cache write | Единица |
|---|---:|---:|---|
| OpenCode Go / Luna | 0.20 | **0.25** | USD/MTok |
| Command Code GOAT / Luna | 0.20 | **0.25** | USD/MTok |
| Command Code GOAT / Sol | 5.00 | **6.25** | USD/MTok |

Для расчёта используются именно ставки канала: например, Command Sol отличается от публичного API Sol. MiMo cache read у OpenCode равна 0.003625, у Command Code — 0.0036; эти значения не приравниваются.

## GLM: единицы и временные сценарии

Исходная формула баллов: `(input × 2.3 + cache × 0.56 + output × 8) / 10 000`. Поэтому базовые ставки Flash составляют **230 / 56 / 800 points/MTok** для обычного входа, чтения кэша и выхода.

Во всех трёх временных сценариях V3 new недельный пул одинаков. Меняются только ставки:

- peak: коэффициент расхода 1;
- off-peak: официальный коэффициент расхода 0.5;
- mid: коэффициент расхода **2/3**, воспроизводящий принятое RAP среднее арифметическое ёмкостей `(1 + 2) / 2 = 1.5`.

Mid — пользовательский сценарий RAP, а не официальный тариф. Это также не распределение токенов 50/50 между peak и off-peak: такое распределение дало бы коэффициент расхода 0.75. Увеличение пула одновременно со снижением ставок запрещено: оно дважды учитывало бы скидку.

Peak указан как пн–пт 14:00–18:00 UTC+8. Месяц из четырёх недель — конвенция проекта, а не дополнительный официальный месячный пул.

**Девять old-строк не рассчитываются:** RAP совмещает старую цену V2 с баллами и коэффициентами V3. Сохранённый источник отмечает различие систем квот V2/V3. Перенос создавал преимущество старого тарифа без подтверждённого права на новую квоту, поэтому его нельзя сохранять как обычное допущение. Строки old остаются в таблице для каждого effort без цены и с объяснением недостающих условий V2; цена не подменяется нулём.

Для шести new peak/off-peak базовые пулы и три ставки официальные; три new mid дополнительно используют условный сценарий времени. Общий пятикомпонентный статус всех девяти new остаётся `assumed` из-за сопоставлений cache write и reasoning. Токенные категории не покрывают возможную отдельную оплату инструментов.

В основном разделе AA 27 доступных описаний исходных квот объединены с 14 API-калибровками: **41 из 65** пар имеют основание для расчёта. Остальные **24** пары сохраняются без подписочной цены. Наличие весов ещё не гарантирует цену каждого effort: в AA могут отсутствовать необходимые расходы.

## Другие существенные ограничения

- OpenCode GLM Flash: research от 2026-09-10 отмечает лимит $60, но принятая таблица сохраняет $15 из 2026-09-06. Здесь сохранены **$15**, как в исходном снимке, с `source_conflicts_ru` и `quota_basis_status=assumed`; это не актуализация цены.
- Command Code: плата $10 не включает processing fee. Точный размер не подтверждён; предположение «$0.80» не принято за официальную ставку. Цена задачи без комиссии ниже полной стоимости оплаты.
- DeepSeek: использованы принятые off-peak ставки. В Ollama peak — пн–пт 12:00–18:00 UTC; у OpenCode и Command Code — 01:00–04:00 и 06:00–10:00 UTC. Во время peak ставки вдвое выше.
- OpenCode Luna и Grok используют нижнюю ценовую ступень контекста: ≤272K и ≤200K соответственно. Суммарных токенов AA недостаточно для восстановления доли запросов выше этих порогов.
- Перенос токенных категорий AA не гарантирует ту же долю cache hits и то же поведение модели на другом канале. Результат описывает стоимость заданного профиля токенов при перечисленных условиях.

## Воспроизводимость и проверка снимка

Генератор читает через `git show` только закреплённый коммит RAP. Текущие веб-страницы не опрашиваются, checkout не меняется. Он сравнивает основные rates и model caps из research с `scripts/build_adopted.py`, затем сохраняет SHA-256 использованных исходников.

```
node scripts/fetch_quota_rates.mjs --rap-root <путь-к-репозиторию-RAP>
node scripts/fetch_quota_rates.mjs --rap-root <путь-к-репозиторию-RAP> --check
```

Автоматически распознаются соседний `real-api-pricing` и размещение проекта внутри `extensions/aa-costs`. `--check` проверяет совпадение существующего manifest с воспроизводимым результатом и не записывает файл.

Перед использованием проверяются `metadata.pricing_revision`, `metadata.pricing_retrieved_at_utc` и `metadata.pricing_rows_sha256`. Последний — SHA-256 UTF-8 строки `JSON.stringify(pricing.rows)` всего массива, включая API. При несовпадении нужен повторный аудит; нельзя молча переносить старые ставки на новый снимок.

Основные закреплённые источники: [build_adopted.py](https://github.com/FeiZhuLulu/real-api-pricing/blob/6489b60a14680a5ce848131d461a90eb054d03ac/scripts/build_adopted.py), [OpenCode](https://github.com/FeiZhuLulu/real-api-pricing/blob/6489b60a14680a5ce848131d461a90eb054d03ac/data/research/opencode-go-round5-2026-09-06.json), [Command Code и Ollama](https://github.com/FeiZhuLulu/real-api-pricing/blob/6489b60a14680a5ce848131d461a90eb054d03ac/data/research/code-subscriptions-round1-2026-09-06.json), [исходные квоты GLM](https://github.com/FeiZhuLulu/real-api-pricing/blob/6489b60a14680a5ce848131d461a90eb054d03ac/data/research/quotas-web-2026-09.json), [сценарии GLM](https://github.com/FeiZhuLulu/real-api-pricing/blob/6489b60a14680a5ce848131d461a90eb054d03ac/data/research/glm-adoption-round4-2026-09-07.json). Модельные дополнения DeepSeek также перечислены в `source_urls` соответствующих строк.
