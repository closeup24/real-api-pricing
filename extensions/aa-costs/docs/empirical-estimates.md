# Практические замеры подписок

Вкладка «AA + подписки» включает подписки с практической основой даже тогда, когда провайдер не опубликовал веса списания. Отсутствие официальной формулы не означает отсутствие данных. При этом измерение и перенос его результата на другую нагрузку показаны отдельно.

## Как выбирается метод

1. При известных credits/points и ставках используются исходные квоты из `quota-rates.json`.
2. Если известна пара «API-эквивалент расхода / доля квоты», она задаёт месячный API-эквивалент. Предполагается, что списание пропорционально API-стоимости; применяется состав AA отдельно для каждого effort.
3. Иначе берётся прошедшая аудит оценка наблюдённого токенного объёма. Стоимость задачи равна месячной плате, умноженной на отношение токенов AA к этому объёму. Сохранение ёмкости при другой смеси — явное допущение.

В третьем методе цена токена одинакова для effort, а в первых двух может меняться из-за состава категорий. Это свойство модели расчёта, не доказательство одинакового расхода квоты в реальном сервисе.

## Покрытие

| Подписки | Применённое основание |
| --- | --- |
| ChatGPT Luna Plus / Pro 5x / Pro 20x | Полный замер Plus; для Pro — перенос ×5/×20, с гипотезой API-весов |
| ChatGPT Astra Pro 5x / Pro 20x | Отдельные токенные замеры с процентами; оговорки о guardian и границах окна |
| ChatGPT Sol и Astra Plus | Принятая наблюдённая ёмкость; для Astra Plus отсутствует output |
| Claude Pro + Opus | Сессионный API-эквивалент и 7% недели; присутствуют Haiku и поиск |
| Claude Max + Opus/Fable | Практические оценки с поправками на промопериод, модельный лимит и перенос между планами |
| Google Pro / Ultra | Наблюдённый API-worth Gemini 3.8; Ultra ×5/×20 |
| Cursor Pro+ | Наблюдённые $214.74 / 26.8%; применение API-весов условно |
| Cursor Pro / Ultra / Fast | Наблюдённые токены / процент; суммы через придуманную смесь не используются |
| SuperGrok / Plus / Heavy | Наблюдённые объёмы и масштабирование; номинальные доллары панели не равны API-долларам |
| Devin Max + Astra | Полный токенный замер и процент недельной квоты; сохраняется сценарий наблюдённой ёмкости |

Для Grok 4.7 один сеанс утрачен, а его доля квоты оценена автором RAP. Новые три пары отмечены как замер с поправками / производные планы. Они не называются независимыми подтверждёнными лимитами.

SuperGrok Lite исключён: исторические 150 млн токенов не сопровождаются проверяемым замером или исходным пулом. Отсутствующая подписочная квота не превращается в бесплатный тариф. Fable на Claude Pro не добавляется: выбранный источник не включает его в подписочную квоту.

## Воспроизведение

Из каталога расширения:

```sh
node scripts/build_empirical_evidence.mjs
```

Генератор использует закреплённый upstream Git commit, существующий аудит `quota-evidence.json` и исходный `pricing.json`. Файл `empirical-evidence.json` содержит ссылки, исходные числа, методы, оговорки и хеши исследовательских файлов. Он не меняет прежний строгий сценарий в архивном отчёте.

`empirical_scenario.mjs` проверяет соответствие снимку и объединяет практические оценки с известными ставками. Исходные API-строки AA остаются неизменными. Недельные замеры нормируются на четыре недели, а общие пулы разных моделей одной подписки не складываются.
